# 🚀 Run Hermes 3 (8B) + Open WebUI on Google Colab (Free T4 GPU)

این پروژه به شما امکان می‌دهد مدل قدرتمند و بدون سانسور **Hermes 3 (8B)** را به همراه رابط کاربری گرافیکی شبیه به چت‌جی‌پی‌تی (**Open WebUI**) به صورت **کاملاً رایگان** روی کارت گرافیک‌های Google Colab بالا بیاورید و از طریق تونل امن Cloudflare به آن متصل شوید.

## 🌟 ویژگی‌ها
- ⚡ اجرای مدل با سرعت بالا روی کارت گرافیک رایگان Nvidia T4
- 💬 رابط کاربری اختصاصی و تمیز با Open WebUI
- 🌐 ایجاد لینک عمومی از طریق Cloudflare Tunnel بدون نیاز به پورت‌فورواردینگ یا آی‌پی ثابت
- 💸 بدون نیاز به خرید سرور و هزینه برای توکن

## 🛠️ پیش‌نیازها
1. یک حساب گوگل (جیمیل)
2. تنظیم Runtime کولب روی **T4 GPU** (از منوی `Runtime` > `Change runtime type`)

## 🚀 نحوه اجرا
کافیه سلول‌های نوت‌بوک را به ترتیب اجرا کنید. در پایان، یک لینک با دامنه `trycloudflare.com` دریافت می‌کنید که رابط کاربری چت شما روی آن فعال است.
